# Archived Scripts

reproduction. They are not the default implementation surface for the active
nuScenes-devkit backend makeover.

- `cp1/`: deferred CP1 semantic-alignment and benchmark evidence tooling.
- `carla/`: post-MVP CARLA feasibility probing.

Use the current handoff before running archived scripts:
`docs/current/nuscenes-devkit-makeover-handoff.md`.
